# Team Notes (Anik's original criteria)

Off the bat, some criteria I made based on what they're saying:
- Focus on **humanizing the problem and the impact**. Hardware is a maybe, but it always looks super impressive.

## Presentation
- Explore how classical computing isn't enough and how quantum actually makes sense as a better alternative. **Don't be sycophantic.**
- Explain how it all works. We have to think outside the box.

## Research
- Half, if not all, of this project is straight research. We don't use quantum where it doesn't make sense. Where it doesn't, we compare, and we can use a **hybrid classical + quantum** approach. We always discuss the limitations.
- Show that we **exhausted all options**: quantum annealing, gate-based (non-annealing), noise accounting, everything quantum. Look at the papers so we understand them ourselves.
- Show it is **based on current research**.
