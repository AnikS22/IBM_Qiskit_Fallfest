Simulated Quantum Annealing: Method

01 DEFINE THE STEP

Write the next wave update as a set of linear equations.

02 ENCODE IN BITS

Represent signed updates with bits. A QUBO score penalizes equation errors.

03 SEARCH

CPU-based SQA seeks low-score bit strings while simulated quantum fluctuations decrease.

04 DECODE & REPEAT

Decode and refine the update; advance time. Repeat to predict the pressure recordings.
